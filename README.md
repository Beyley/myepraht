# myepraht

[Letroso](https://letroso.com/en/) hanegrev hei Shpre Yhng dei Zig.

Nwnyen Chamina nirh pwn 24-bit (X-Term, GNOME Terminal, Konsole, Windows Terminal).

## fing

1. Dahf Zig `0.15.2` hechin [ziglang.org](https://ziglang.org/download/) chev OS shre.
2. Dahf [Git](https://git-scm.com/install/).
3. `$ git clone https://github.com/Beyley/myepraht`
4. `$ zig build -Doptimize=ReleaseSafe` (chev `-Doptimize=Debug` hei sarei)
5. `$ zig-out/bin/myepraht`
